# 🔥 Abdallah-Recon

Advanced Automated Reconnaissance Framework by Abdallah

---

## 🚀 Features

- Subdomain enumeration (subfinder, amass, crt.sh)
- DNS resolution (dnsx)
- Live host detection (httpx)
- URL harvesting (gau + waybackurls)
- Parameter extraction
- JS file discovery
- Vulnerability scanning (nuclei)
